Employee Accounts API - Technical Design

Living architecture document for the Employee Accounts application

Project Goal

Learn Python by building a real application that communicates with the Employee Accounts API. The objective is not simply to call an API, but to progressively build a clean architecture similar to a .NET application while learning Python fundamentals one concept at a time.

Project Structure

PythonAPI_App/
│
├── main.py               # Application entry point
├── api_response.py       # Makes the HTTP request
├── models.py             # Future model classes
├── emp_accts_repository.py (optional repository)
├── requirements.txt
└── README.md
